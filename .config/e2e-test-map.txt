# End-to-end test map for scripts/changed-tests.sh (`make test-changed`, CI's
# coverage-changed).
#
# A change to crates/<c>/src selects only <c>'s own tests, but the tests that
# exercise that source often live in another crate (intentd's end-to-end
# suites, or another crate's unit tests). Each entry below makes a change to
# matching source also run the named module, so PR CI catches the break
# instead of the merge queue (intentd#2617: a script-binding change in intent-acp broke
# e2e_wss_hook_mcp_tools::script_monitors, which only coverage-e2e ran).
#
# Format, one entry per line (`#` starts a comment line):
#   <source glob>  <crate>::<test binary>  [<module path>]
# - <source glob>: a Bash pattern matched against the repo-relative path of a
#   changed file; `*` also matches `/`.
# - <crate>::<test binary>: the nextest binary id, e.g. intentd::suite_wss_g_r
#   (the cargo [[test]] target, root file crates/<crate>/tests/<binary>.rs),
#   or <crate>::lib for the crate's library unit tests (root file
#   crates/<crate>/src/lib.rs; the crate must not also have a tests/lib.rs).
# - <module path>: the test-name prefix inside that binary, e.g.
#   e2e_wss_hook_mcp_tools::script_monitors or, for a lib,
#   model_preference::tests; omit it to run the whole binary.
# The selection is `--test <binary> -E 'binary_id(=<crate>::<binary>)&test(/^(<module path>)::/)'`,
# or `--lib -E 'binary_id(=<crate>)&test(/^(<module path>)::/)'` for <crate>::lib.
#
# `scripts/changed-tests.sh --check-map` (CI's release-scripts job, and every
# selection run) fails when a glob matches no file or a binary or module no
# longer exists. Editing this file runs every module it names.
